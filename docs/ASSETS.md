# Interface assets

- `models/ds-lite/`: supplied by the user in `nintendo-ds-lite.zip`. The original `DS mapped.fbx` was converted to GLB without reshaping geometry; its texture UV convention is preserved. Shell texture and bump map retained. In setup the screen regions are painted at runtime with Tandem content. The archive contains no author/license manifest; no separate license is asserted here.
- `environments/studio-small-09.hdr`: [Studio Small 09](https://polyhaven.com/a/studio_small_09) by Sergej Majboroda, Poly Haven, CC0. The 2K HDR provides photographed studio lighting and reflections. The render pipeline uses multisampled targets, supersampling, GTAO and tone mapping. No artificial floor-shadow plane is used.
- `models/cartridge/`: [Nintendo Ds cartridge (preset)](https://sketchfab.com/3d-models/nintendo-ds-cartridge-preset-01e161c3e7c24b40888fdf94ad003501) by [littlengvfx](https://sketchfab.com/littlengvfx), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), supplied by the user in `nintendo-ds-cartridge-preset.zip`. Original mesh and shell UVs retained. Changes: normalization/orientation for display, official game artwork substituted for the sample image, label material adjusted to nonmetallic paper. The archive references a missing `presetNdsiCartridgeFront2.png`; that narrow shell surface reuses its supplied front atlas. Geometry is unchanged. The authored cartridge and dock were removed.
- `art/black2.png`, `art/white2.png`: Nintendo DS box artwork from [libretro-thumbnails](https://github.com/libretro-thumbnails/Nintendo_-_Nintendo_DS/tree/master/Named_Boxarts). The retail spine is cropped through texture UV offset/repeat for the model’s replaceable label. Original source resolution limits the artwork; the shell is actual geometry. Game artwork remains the property of its rights holders; no independent redistribution license is claimed.
- Tandem mark: authored SVG. Splash treatment adapted from the user’s [Fresco](https://github.com/aoyun2/fresco) application.
- Runtime rendering uses Three.js under its MIT license.

The earlier keycap model, prerender cartridge, Pokémon sprites and recorded demo footage have been removed from the application assets.

- `models/tomo/keyboard.glb` (not used by any view since the input page became DS-only): user-supplied `red-mechanical-keyboard-monokei-x-tgr-tomo.zip`. Converted from Blender; original key geometry, legends and UVs retained. Keys separated for travel, with homing marks attached. Red case material adapted for glTF lighting. No author/license manifest supplied; no separate license asserted.
- DS Slot-1 preparation removes the source cartridge/cover within its measured opening.
- Emulator core (not bundled): [melonDS DS](https://github.com/JesseTG/melonds-ds) 1.4.0 by Jesse Talavera and the melonDS team, GPL-3.0-or-later, loaded from `vendor/melondsds/`. Distribution obligations are unresolved.
- `sfx/`: link and cartridge sounds from Kenney's [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds), [Impact Sounds](https://kenney.nl/assets/impact-sounds) and [Interface Sounds](https://kenney.nl/assets/interface-sounds), CC0 (licence in `sfx/LICENSE-kenney.txt`): lowFrequency_explosion_000, spaceEngineLow_000, impactSoft_medium_001, impactPunch_heavy_000, switch_002. Boot sounds: Mixkit 914 "Sci fi click" under the [Mixkit Sound Effects Free License](https://mixkit.co/license/#sfxFree), and Kenney impactMetal_heavy_002 (CC0) for each screen locking on. Mixkit's licence forbids redistributing the files on their own; its full text has not been reviewed.
